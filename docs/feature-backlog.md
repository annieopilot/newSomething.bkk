# ฟีเจอร์ที่จะทำ (Backlog)

รายการฟีเจอร์ที่คุยกันแล้วแต่ยังไม่ได้ทำ — ก่อนเริ่มทำข้อไหน ให้เสนอแผนและรอให้เจ้าของร้านสั่งเริ่มก่อน

---

## 1. ถ่ายรูปใบเสร็จส่ง LINE → บันทึกรับเข้า (สถานะ: วางแผนแล้ว ยังไม่ทำ)

**เป้าหมาย:** ลดการพิมพ์ตอนรับของ — ถ่ายรูปใบเสร็จส่งเข้ากลุ่ม LINE แล้วให้ AI (Claude) อ่านเป็นรายการรับเข้า

### วิธีใช้ (ตามแผน)
1. พิมพ์ `/รับรูป` แล้วส่งรูปใบเสร็จตามภายใน 5 นาที (หลายรูปได้)
2. บอทตอบทันทีว่า "กำลังอ่านใบเสร็จ..."
3. บอทส่งผล เช่น
   ```
   📸 อ่านใบเสร็จได้ 4 รายการ
   ✅ ผงมัจฉะ Uji +1,000 กรัม @1.2฿
   ✅ นมสด Meiji 2L +6 ขวด
   ⚠️ "ขนมปังกรอบ" ไม่มีในสต็อก (ข้าม)
   ```

### ข้างหลังทำอะไร
- ดึงรูปจาก LINE: `GET https://api-data.line.me/v2/bot/message/{messageId}/content`
- ส่งรูป + รายการสินค้าในสต็อก (ชื่อ, หน่วยนับ, หน่วยซื้อ, ขนาดบรรจุ) ให้ Claude จับคู่กับสินค้าและแปลงหน่วยในครั้งเดียว
  ตอบกลับเป็น JSON ตาม schema (structured outputs: `output_config.format`) ใช้ SDK `npm:@anthropic-ai/sdk`
- ใช้ระบบบันทึกเดียวกับ `/รับ` (`supabase/functions/_shared/receive.ts`): movement `purchase`, ราคา → `unit_cost`,
  ชื่อคนรับ, `line_receipts` สำหรับ `/ยกเลิกรับ`
- Claude ใช้เวลา 10–30 วินาที → ตอบ webhook 200 ก่อน แล้วประมวลผลเบื้องหลัง (`EdgeRuntime.waitUntil`)
  ตอบด้วย replyToken (ฟรี) ถ้ายังทัน ถ้าไม่ทันค่อย push (กินโควตา LINE — เช็กด้วย `canPush`)
- ต้องมี secret `ANTHROPIC_API_KEY` ใน Supabase
- ไม่เก็บรูป อ่านเสร็จทิ้ง

### ค่าใช้จ่ายโดยประมาณ (ต่อใบเสร็จ — ประมาณจากขนาดรูป + รายการสินค้า ~55 รายการ ต้องวัดจริงอีกที)
| โมเดล | ราคา ต่อ 1M token (เข้า/ออก) | ต่อใบ | หมายเหตุ |
|---|---|---|---|
| Claude Opus 5.5 (`claude-opus-5-5`) — แนะนำ | $4 / $20 | ~฿1–2 | แม่นสุด อ่านลายมือไทย/บิลเลือนได้ดีกว่า |
| Claude Haiku 5.5 (`claude-haiku-5-5`) | $0.10 / $0.50 | ~฿0.05 | ถูกมาก แต่พลาดง่ายกว่ากับบิลเขียนมือ |

### เรื่องที่ยังต้องตัดสินใจก่อนเริ่ม
1. วิธีเริ่ม: พิมพ์ `/รับรูป` ก่อนส่งรูป (แนะนำ) หรือให้อ่านทุกรูปในกลุ่ม
2. บันทึกทันที + `/ยกเลิกรับ` หรือแสดงผลก่อนแล้วพิมพ์ `/ยืนยัน` (แนะนำ เพราะอ่านรูปพลาดง่ายกว่าข้อความพิมพ์)
3. โมเดล: Opus 5.5 หรือ Haiku 5.5
4. ขอรูปใบเสร็จจริง 1–2 ใบ (บิลพิมพ์/เขียนมือ) ไว้ปรับ prompt
5. มี API key ของ Anthropic หรือยัง

## ไอเดียอื่นที่เสนอไว้ (ยังไม่ได้ตัดสินใจ)

- **`/เสีย` ใน LINE** — บันทึกของเสีย/ทำหก/หมดอายุ (movement `waste` มีอยู่แล้ว ใช้ตัวอ่านเดียวกับ `/รับ`)
- **อัปเดตต้นทุนอัตโนมัติตอนรับเข้า** — ราคาที่ใส่ใน `/รับ` ยังไม่ไปอัปเดต `items.cost_per_unit`
- **`/สั่ง` ใน LINE** — ส่งรายการของที่ต้องสั่ง (หน้า `/order`) แยกตามร้านเข้ากลุ่ม
- **เตือนรายการที่ไม่ได้นับนาน** — เช่น ทุกเช้าบอกรายการที่ไม่ได้นับเกิน 7 วัน
- **สรุปประจำสัปดาห์ใน LINE** — ใช้อะไรไปเท่าไหร่ คิดเป็นเงิน + ของเสีย (จาก `stock_daily_snapshots`)
- **สูตรเมนู + ยอดขาย** — เทียบของที่ควรใช้กับที่นับได้จริง (ต้องมีข้อมูลยอดขายจาก POS ก่อน)
